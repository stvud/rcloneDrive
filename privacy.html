Google API Services User Data Policy Disclosure

rcloneDrive's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

1. Overview and Architecture

rcloneDrive is a personal, client-side configuration designed for interacting with Google Drive via the open-source command-line software Rclone.

This project operates with a strictly decentralized, zero-server architecture. There is no web service, centralized database, backend server, analytics agent, or intermediate proxy operated by rcloneDrive. All communication occurs directly and securely between your personal device and Google's official API servers.

2. Information We Access

When you configure Rclone to connect to your Google Drive account, the application requests access to Google APIs via OAuth 2.0:

  • OAuth Authentication Credentials: Temporary access tokens and persistent refresh tokens granted by Google during the OAuth consent flow.
  • Google Drive Files & Metadata: File content, folder structures, file names, file sizes, MIME types, and modification timestamps contained within your Google Drive account necessary to perform user-instructed file synchronization.

3. How Information Is Used

Information accessed through the Google Drive API is used solely for the following explicit user-directed purposes:

  • To list files and directories when running inspection commands (e.g., rclone ls, rclone lsd).
  • To upload, download, and copy files between your local system and Google Drive as initiated by you (e.g., rclone copy, rclone sync).
  • To mount Google Drive as a local filesystem volume if using rclone mount.

4. Storage and Data Retention

Local Storage Only: All OAuth tokens, credentials, and downloaded files are stored strictly on your local device (in your local Rclone configuration file, typically located at ~/.config/rclone/rclone.conf on Linux/macOS or %APPDATA%\rclone\rclone.conf on Windows).

No file contents, user metadata, or authentication credentials ever touch, pass through, or persist on any server owned or operated by this project or any third party.

5. Third-Party Sharing and Disclosure

We do not sell, rent, trade, lease, or transfer your personal data or Google Drive contents to any third party.

All API calls travel exclusively over encrypted Transport Layer Security (HTTPS/TLS) directly from your computer to Google APIs (https://www.googleapis.com).

6. How to Revoke Access or Delete Data

You maintain full control over your Google account and credentials at all times:

  • Revoke OAuth Access via Google: You can immediately disconnect this application from your Google account at any time by visiting Google Account Security > Third-party apps with account access and clicking Remove Access.
  • Delete Local Credentials: You can permanently delete all locally stored access tokens by running rclone config delete <remote_name> in your terminal or by deleting your rclone.conf configuration file.

7. Security Measures

Rclone supports client-side configuration encryption. You may protect your local configuration and OAuth tokens with an encryption password by running rclone config and choosing the encryption password option.

8. Contact Information

If you have any questions or concerns regarding this Privacy Policy or your data, you may open an issue on the project's GitHub repository or contact the project maintainer directly through your configured developer contact email.
