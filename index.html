How rcloneDrive Works

Architected specifically for private, high-performance file synchronization with zero intermediate infrastructure.

Zero Intermediate Servers

Your local Rclone client talks directly to Google's official API servers (googleapis.com) over encrypted TLS. No telemetry, proxy, or server ever intercepts your traffic.

Local Credential Storage

Your OAuth Client ID, Secret, and tokens reside solely inside your local configuration file (~/.config/rclone/rclone.conf) on your own machine.

Dedicated API Quota

By using your own Google Cloud OAuth credentials rather than shared defaults, you avoid "rate limit exceeded" errors and enjoy fast, dedicated upload/download throughput.

Google API Scopes Requested

To perform backup and synchronization tasks requested by the user, Rclone utilizes the following Google Drive OAuth scopes:

https://www.googleapis.com/auth/drive

Full access to create, read, update, and delete files in Google Drive for comprehensive backup & sync operations.

Primary Scope
https://www.googleapis.com/auth/drive.file

Alternative restricted scope: Only access files and folders created or opened by this specific app.

Optional Scope
Google API Limited Use Notice: rcloneDrive strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Configuring Rclone with Your OAuth Client

Step-by-step instructions to link your private Google Drive client with the Rclone CLI.

1

Create OAuth Client ID in Google Cloud

In your Google Cloud Console project, go to APIs & Services > Credentials, click Create Credentials > OAuth client ID, choose Application type: Desktop app, name it rcloneDrive, and click Create. Copy your Client ID and Client Secret.

2

Run Rclone Configuration

Open your terminal and run the interactive setup:

rclone config

Select n for New remote → Name it gdrive → Select drive (Google Drive) as the storage type → Paste your personal Client ID and Client Secret when prompted.

3

Authorize & Start Syncing

Rclone will open your web browser to Google's OAuth consent screen. Sign in with your Google account and grant access. Test your connection with: 

rclone lsd gdrive:
